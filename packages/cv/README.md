# The collection of util functions in CV

Note: Put cv folder under your code home directory

    .
    ├── cv
    ├── your_code.ipynb

1. img_vid.py
  images to video
  images to gif
  video to images

2. video_info.py
  general info: frame no, fps, video length
  frame number
  fps: frame per second
  video length

3. video_cut.py
  cut out part of video
  cut video into a series of segments
  lower fps
  merge videos

4. utils.py
  make folder
  extract number in file name
  extract alpha in file name
  get file list in a folder
  ignore warnings
  no outputs at all
  no outputs in one block
  save list/dict in json
  load list/dict in json

5. draw.py
  generate random color
  cv2 draw rectangle, line, circle/point, text

6. metric.py
  convert Yes/No into 1/0 in list
  metrics like TPR, FPR
